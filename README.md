# Image Prompt Builder

> 为 ChatGPT / OpenAI Images、Gemini / Nano Banana 等图像生成工具构建**可直接复制的图像提示词**，并支持**多系列 Markdown 图像提示词集**的 Claude Code Skill。  
> A Claude Code Skill that builds **copy-paste-ready image prompts** for ChatGPT / OpenAI Images, Gemini / Nano Banana, and similar image tools, with support for **multi-series Markdown image-prompt sets**.

---

## 中文版本

### 简介

**Image Prompt Builder** 是一个 Claude Code Skill，用于把用户对图像、插图、海报、信息图、科学图解、流程图或概念视觉的模糊描述，转化为可直接粘贴到图像生成工具中的高质量提示词。

它默认输出英文 canonical prompt，并提供完整中文审阅版，方便中文用户确认英文提示词是否准确表达了视觉需求。对于多个图像系列，它可以生成一个完整的 Markdown 提示词集文件，包含统一视觉规范、系列目标、每张图的英文提示词、中文审阅版本、推荐参数和后处理注意事项。

### 核心能力

- 为 ChatGPT / OpenAI Images、Gemini / Nano Banana、Nano Banana Pro 或其他图像工具构建提示词
- 支持四类主要图像模板：
  - 信息图、海报、封面
  - 科学插图
  - 概念视觉探索
  - 流程图、框架图、过程图
- 支持单图提示词、批量提示词和多系列 Markdown 提示词集
- 输出英文提示词 + 中文审阅版本
- 自动提示推荐参数：比例、质量/分辨率、是否使用参考图、是否启用推理/高质量模式
- 提供后处理检查：文字、形态、比例、颜色语义、出版级重绘建议

### 红线：不适合图像模型的任务

本 Skill 会拒绝或重定向以下图件，不会把它们包装成图像生成提示词：

- 真实数据图：柱状图、折线图、箱线图、热力图、时间序列等
- 真实地图：行政边界、河网、站点位置、真实坐标、流域图等
- 真实网络拓扑：食物网、生态网络、社会网络、引用网络、交互矩阵可视化等
- 精确数值图：金融曲线、水文过程线、模型输出图、生态指标图等
- 任何需要依赖视觉准确性做决策的图件

推荐替代工具：

| 图件类型 | 推荐工具 |
|---|---|
| 真实数据图 | R / Python |
| 真实地图 | QGIS / ArcGIS |
| 真实网络拓扑 | igraph / Gephi / Cytoscape / cheddar |
| 可编辑流程图 | Mermaid / draw.io |
| 精确公式或化学结构 | LaTeX / ChemDraw |

### 设计原则

1. **英文 canonical prompt，中文用于审阅**  
   英文提示词用于粘贴到图像工具，中文版本用于确认语义是否准确。

2. **先做红线检查，再写提示词**  
   数据、地图、网络拓扑和精确数值图不能交给图像模型凭空生成。

3. **单个提示词必须自包含**  
   用户应能复制任意一个英文 prompt 独立运行。

4. **多系列提示词必须有统一视觉规范**  
   系列之间可以变化，但不能变成互不相关的 prompt 堆。

5. **正式交付必须后处理**  
   图像模型适合生成视觉壳、构图和风格方向；出版级图件仍需检查文字、比例、物种形态和矢量重绘。

## English Version

### Introduction

**Image Prompt Builder** is a Claude Code Skill that turns a rough visual brief into high-quality prompts for image-generation tools such as ChatGPT / OpenAI Images, Gemini / Nano Banana, Nano Banana Pro, or similar systems.

It outputs an English canonical prompt for copy-paste use and a complete Chinese parallel version for audit. For multi-image projects, it can generate a full Markdown prompt-set file containing shared visual identity, series goals, English prompts, Chinese audit versions, recommended parameters, and post-processing notes.

### Core Capabilities

- Build prompts for ChatGPT / OpenAI Images, Gemini / Nano Banana, Nano Banana Pro, or other image tools
- Support four main figure templates:
  - Infographics, posters, covers
  - Scientific illustrations
  - Concept art and style exploration
  - Process diagrams, framework diagrams, workflow visuals
- Support single prompts, batch prompts, and multi-series Markdown prompt sets
- Output English prompt plus Chinese audit version
- Recommend parameters such as aspect ratio, quality/resolution, reference-image use, and reasoning/high-quality mode when available
- Add post-processing checks for text, morphology, proportions, color semantics, and publication redraw needs

### Red Lines: Not for Image Models

This Skill refuses or redirects figure types that should not be generated by image models:

- Real-data charts: bar charts, line charts, box plots, heatmaps, time series, etc.
- Real maps: administrative boundaries, river networks, station locations, coordinates, watershed maps, etc.
- True network topologies: food webs, ecological networks, social networks, citation networks, interaction matrices, etc.
- Precise numerical plots: finance charts, hydrological series, model outputs, ecological metrics, etc.
- Any figure where decision-making depends on visual accuracy

Recommended alternatives:

| Figure Type | Recommended Tool |
|---|---|
| Real-data charts | R / Python |
| Real maps | QGIS / ArcGIS |
| True network topologies | igraph / Gephi / Cytoscape / cheddar |
| Editable process diagrams | Mermaid / draw.io |
| Exact equations or chemical structures | LaTeX / ChemDraw |

### Design Principles

1. **English canonical prompt, Chinese audit version**  
   The English prompt is intended for the image tool; the Chinese version helps verify meaning.

2. **Run the red-line check before prompting**  
   Data, maps, topology, and precise numerical visuals require proper tools, not image-model guesses.

3. **Every prompt must be standalone**  
   The user should be able to copy any English prompt and run it independently.

4. **Multi-series prompt sets need shared visual identity**  
   Series should vary intentionally, not become unrelated prompt piles.

5. **Formal deliverables require post-processing**  
   Image models are useful for visual shells, composition, and style direction; publication figures still need text checks, morphology checks, proportion checks, and often vector redraw.
